SQL Injection Prevention

Unsafe Query 

SELECT * FROM users
WHERE username='admin' OR '1'='1';

The attacker changes the SQL query and bypasses authentication.

Secure Query 

db.query(User).filter(
    User.username == username
)

SQLAlchemy automatically parameterizes queries, preventing SQL injection attacks.

Security Layers

  • Password hashing using bcrypt
  • Encrypted sensitive employee information
  • Capability code authentication
  • Parameterized SQL queries
  • Authenticated user sessions
